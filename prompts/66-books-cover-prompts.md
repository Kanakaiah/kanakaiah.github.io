# Remora 66 Books Cover Art Prompts

This document contains the official image generation prompts for all **66 Book Cover cards** in the Remora Bible app (Old Testament & New Testament).

These images serve as the primary visual identity for each book across the Bible Browser, Home Dashboard, and Theme Flashcards.

- **Aspect Ratio:** 4:3 (or 16:9 widescreen depending on target view)
- **Destination Paths:**
  - Web (PWA): `public/books/<bookId>.png`
  - Android: `android/app/src/main/assets/books/<bookId>.png`
